# Documentacao do Projeto

Este diretorio concentra os arquivos de apoio e referencia do `EstoquePro`.

## Arquivos atuais

- `VISAO_E_ESCOPO_DO_SISTEMA.md`: descricao funcional e objetivo geral do sistema.
- `CASOS_DE_USO_DO_SISTEMA.md`: atores, casos de uso e diagrama funcional do sistema.
- `DIAGRAMA_DE_CLASSES_DO_SISTEMA.md`: visao das classes de dominio e servicos centrais.
- `MODELO_ENTIDADE_RELACIONAMENTO_MYSQL.md`: DER logico e orientacao de uso no MySQL.
- `RELATORIO_VALIDACAO_COMUNIDADE.md`: base textual da entrega de validacao com campos preenchiveis e secao tecnica consolidada.
- `RELATORIO_VALIDACAO_COMUNIDADE.html`: versao formatada para impressao/exportacao em PDF.
- `mysql_workbench_diagrama_er.sql`: script fisico para gerar o modelo no MySQL Workbench.

## Convencao sugerida

- manter neste diretorio apenas documentacao versionada e artefatos de apoio relevantes ao projeto;
- usar `docs/tmp/` para rascunhos locais que nao devem ir para o Git;
- registrar documentos novos aqui e referencia-los no `README.md` da raiz quando forem importantes para onboarding.
