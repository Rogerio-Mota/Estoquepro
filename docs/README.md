## Convencao sugerida

- manter neste diretorio apenas documentacao versionada e artefatos de apoio relevantes ao projeto;
- usar `docs/tmp/` para rascunhos locais que nao devem ir para o Git;
- registrar documentos novos aqui e referencia-los no `README.md` da raiz quando forem importantes para onboarding.
